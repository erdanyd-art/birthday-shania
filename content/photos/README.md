# Photos

Put original photo files here (JPG, PNG, WebP or AVIF), then name them in
`content/archive.ts`, `content/messages.ts` or `content/letter.ts`.

- Use the original file. Photos sent through WhatsApp as "photo" are heavily
  compressed; send them as a document instead.
- No need to resize or convert: the build makes small, fast versions automatically.
- File names are case-sensitive: `Childhood.JPG` and `childhood.jpg` are different.
